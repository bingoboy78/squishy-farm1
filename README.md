# squishy-farm1
Уютная игра для изучения таблицы умножения. Устанавливается на главный экран и работает офлайн.

## Играть

[Открыть Сквиши-Ферму](https://bingoboy78.github.io/squishy-farm1/)

## Добавить на Android

1. Откройте ссылку в Chrome на телефоне.
2. Нажмите «Установить» в игре, если кнопка появилась. Либо откройте меню Chrome ⋮ → «Добавить на главный экран» → «Установить» (названия могут отличаться).
3. Дождитесь надписи «Можно играть без интернета». На главном экране появится значок с котиком.

Если ссылка открылась внутри мессенджера, сначала выберите «Открыть в браузере».

## Как играть

Таблицы ×2–×10, по десять примеров на уровень. Введите число экранными цифрами или физической клавиатурой и нажмите «Проверить». Ошибочный пример вернётся позже. За пройденный уровень открывается сквиши. Звук можно отключить кнопкой с нотой.

Прогресс хранится только в браузере на этом устройстве. Он сохраняется между запусками и при переключении таблиц. Между телефоном и компьютером не синхронизируется; прогресс из локального HTML-файла автоматически не переносится. Очистка данных сайта удалит сохранение.

## Мега-бонус: примеры вразброс

Когда собраны все девять сквиши за таблицы ×2–×10, открывается особый раунд. В нём десять разных примеров: представлены все девять таблиц, один дополнительный пример выбирается случайно. Пары вроде 3×4 и 4×3 в одном раунде не дублируются.

За все десять решённых примеров в коллекции навсегда появляется десятый, легендарный сквиши — Лунный дракон с крылышками и короной. Ошибки возвращаются в конец очереди, награда ждёт решения всех примеров. Раунд можно прерывать и продолжать или проходить повторно. Старый прогресс сохраняется при обновлении приложения.

## Устройство приложения

Статический HTML/CSS/JavaScript, без сторонних библиотек, аналитики, рекламы и регистрации. Внешних шрифтов и медиа нет. Service worker сохраняет файлы для офлайн-запуска. Манифест использует относительные пути, поэтому сайт работает в подкаталоге GitHub Pages. Сам GitHub обрабатывает запросы к размещённому сайту согласно своим правилам.

Публикация: GitHub Pages → Deploy from a branch → main → / (root).
Для обновления офлайн-версии изменяйте версию CACHE в sw.js вместе с файлами приложения. Если новая версия ждёт установки, на главной странице появляется «Обновить игру».

index.html также работает локально без установки PWA. Для размещения и работы офлайн через браузер нужен весь комплект файлов.
